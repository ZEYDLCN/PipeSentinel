# packages/contracts

Faz 1'de data contract tanımları `src/pipeline_sentinel/contracts.py`
içinde Python sözlükleri olarak tutuluyor (`DEFAULT_CONTRACTS`). Bu
paket, contract'lar ayrı bir JSON Schema/dbt-benzeri formata taşınıp
birden çok dil/servis arasında paylaşılması gerektiğinde (Faz 2+)
kullanılacak.
